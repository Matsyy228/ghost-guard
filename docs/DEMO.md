# Демонстрация GHOST//GUARD

Перед показом откройте `http://127.0.0.1:5173/` с масштабом браузера 100%. Проверьте, что в верхней строке написано «API подключён». Команда `.\.venv\Scripts\python.exe -B -m backend.version --check` сверит сборку запущенного backend с исходниками.

1. Выберите **Демо**, нажмите **Вернуть шаблон** и запустите проверку. Интерфейс откроет отчёт с тремя учебными находками. Статус **BLOCK** объясняется высокой критичностью одной из них.
2. Раскройте первую находку. Покажите файл, строку, правило и рекомендацию сканера. Если в отчёте есть пояснение модели, оно появится отдельным разделом. Встроенный шаблон не требует запущенной модели.
3. В сценарии измените минимальную критичность условия с высокой на критическую. Повторный запуск пойдёт по ветке «Нет». Статус выпуска останется **BLOCK**, поскольку правило по-прежнему нашло риск высокого уровня.
4. Проверьте фильтр критичности и выгрузку JSON.

## Если API недоступен

Откройте **Резервный демо-отчёт** в блоке источника. Интерфейс покажет сохранённый отчёт встроенного учебного проекта. В обзоре будет пометка «ПРИМЕР», а в отчёте — сообщение, что новый анализ не выполнялся. Файл можно скачать как `ghost-guard-demo-report.json`. Для живого запуска восстановите API и нажмите **Проверить подключение**.

Резервный отчёт хранится в `frontend/demo-report.json`. При изменении учебного проекта обновляйте его из терминального события `result` обычного демо-запуска, сохраняя поля `report` и `release_gate`.
