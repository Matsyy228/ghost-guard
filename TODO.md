# План GHOST//GUARD на 45 часов

GHOST//GUARD помогает небольшой команде собрать проверку Kotlin-проекта перед релизом и увидеть, какая находка повлияла на решение. Встроенное демо даёт по одной синтетической находке от Secrets, SCA и SAST. Порог `high` выбирает ветку **Да**, `critical` на том же наборе выбирает **Нет**.

## Обязательная часть кейса

| Требование | Текущее состояние |
| --- | --- |
| Загрузка учебного Kotlin/Spring Boot проекта с Gradle Kotlin DSL | ZIP и свой JSON-справочник проверены на синтетических файлах |
| Свои Secrets, SCA и SAST с критичностью, файлом и строкой | Работают на демо. Сверка с эталоном организаторов впереди |
| Визуальный редактор и исполнение по связям | Добавление, перемещение, настройки, связи и удаление нод проверены в Edge |
| `if/else`, сравнения и регулярные выражения | Обе ветки и защита от циклов проверены в Edge |
| Ручной запуск и запуск по расписанию | Ручной запуск работает. Расписание впереди |
| Статусы, входные данные и результаты по нодам | Работают для ручного запуска |
| LLM объясняет находки, приложение проверяет структуру и ссылки | Впереди |
| Реальное оповещение по одному каналу | Целевой канал команды — Telegram. Интеграция впереди |

Для проверок используются учебные проекты организаторов и собственные безопасные синтетические примеры. Поиск выполняют самописные сканеры, LLM объясняет их результаты. После обязательной части можно брать задачи со звёздочкой: генерацию графа по тексту, библиотеку шаблонов и CI/CD.
